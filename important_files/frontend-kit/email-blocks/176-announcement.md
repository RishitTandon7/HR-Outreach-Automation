# Announcement 176

A flexible email template block intended for visual campaign composition.

## Intent

Provide a clear, focused experience that works on desktop and mobile.

## Visual direction

- Warm neutral canvas with high-contrast ink text
- Coral used sparingly for primary emphasis
- Rounded surfaces and calm, generous spacing

## Implementation notes

Use semantic HTML, visible focus states, and responsive layout rules.

## Variant

Variant 176 is ready to be adapted to the campaign dashboard.
